# GPUI visual baselines

Baseline and QML-render PNGs are local comparison artifacts and are ignored by Git. Regenerate GPUI references with the capture instructions below; QML mock renders can be recreated with `scripts/shot.py`.

`chat-budi-1100.png` and `chat-budi-800.png` are dark GPUI references for the QML chat shell; matching light references are `chat-budi-light-1100.png` and `chat-budi-light-800.png`. `chat-budi-collapsed-1100.png` captures the collapsed-sidebar state. The normal chat pairs use 1100×720 and 800×540. `login-qr-1100.png`, `login-phone-1100.png`, `calls-history-1100.png`, `calls-detail-1100.png`, `calls-incoming-chat-1100.png`, `calls-active-chat-1100.png`, `status-list-1100.png`, `channels-list-1100.png`, and `settings-1100.png` capture those routes at 1100×720. `chat-info-drawer-1100.png` and `chat-group-info-drawer-1100.png` capture the current direct-contact and group-info drawers at 1100×720. Incoming and active call overlays also have 800×540 references. The pre-existing references were captured on 2026-10-16. The direct/group info captures were added on 2026-10-17. All were captured under Xvfb using Mesa llvmpipe, isolated temporary settings, and local `tests/mock_backend.py` fixtures (`chats`, `rich`, `calls`, `composer`, `bot`, `status`, and `channels`). Matching QML captures are in `../screenshots/`, including the paired direct/group Info drawers, direct/group Message Info sheets, Search drawer, Starred drawer and Starred pages layout, the light chat pairs, `chat-sidebar-collapsed-mock.png`, both 800×540 call-overlay captures, and the corresponding dark chat, Login, Calls, Status, Channels, and Settings filenames. The refreshed direct/group Info, the Add-member picker, direct/group Message Info, Search, and Starred QML captures use `QT_QPA_PLATFORM=xcb` under Xvfb with Mesa llvmpipe and the same 28% window transparency; the offscreen QtQuick renderer did not display the masked avatar photos.

All captures use mock content at 100% UI scale. The dark pairs use `default-dark`; the light chat pairs use `default-light`. GPUI's default window transparency is 28%; matched QML screenshots use `--window-transparency 28` and flatten alpha over the black Xvfb root so both captures use the same backdrop. The QML chat cards now use GPUI's dark/light bubble fallback and full-width poll/location/contact actions. The two clients' visible message windows and timestamps differ slightly, so compare component geometry and treatment rather than treating the captures as identical data. The chat list measures 360 px in the paired chat captures; the Calls pane measures 360 px, Status pane 340 px, and Channels pane 340 px. GPUI draws a 16 px inset client frame/shadow margin; QML now draws the same inset and 10 px corner radius for a restored window, while its soft frame shadow remains to be compared. These references do not constitute a full visual-parity sign-off.
