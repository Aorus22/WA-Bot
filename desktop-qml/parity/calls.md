## Remaining verification

The Go router exposes `POST /api/calls/{id}/media-session` and returns the one-use token, expiry, call ID, and WebSocket path. QML encodes/decodes baseline H.264 Annex-B with the host GStreamer OpenH264 elements and forwards keyframe requests to the encoder. The binary frame header, kinds, metadata, size limit, and `?token=` URL match the Go implementation.

The history and selected-call detail pairs use local mock fixtures at 1100×720. Incoming and active overlays use the same chat background and call/contact data at 1100×720 and 800×540. Screenshots and tests do not prove camera/microphone permissions, device switching, A/V sync, reconnects during an active call, or long-call stability. The host must provide GStreamer with `openh264enc`, `openh264dec`, and `h264parse`.
