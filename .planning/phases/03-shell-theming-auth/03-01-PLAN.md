<objective>
Mengimplementasikan Theme Engine dan katalog lengkap 81 preset warna dari `web/src/data/themes.ts` ke dalam representasi Rust strongly typed, lengkap dengan konversi hex ke Hsla/Rgba, deteksi luminance, mode System/Light/Dark, sinkronisasi persistensi via `wabot-settings`, dan dynamic hot-swapping.
</objective>

<tasks>

2. Buat modul `theme/color.rs` dan `theme/preset.rs` yang mendefinisikan 17 semantic token warna CSS (`background`, `foreground`, `card`, `cardForeground`, `primary`, `primaryForeground`, `secondary`, `secondaryForeground`, `muted`, `mutedForeground`, `accent`, `accentForeground`, `destructive`, `destructiveForeground`, `border`, `input`, `ring`) dan meng-embed seluruh 81 preset web 1:1.
3. Buat modul `theme/manager.rs` dengan `ThemeManager` global GPUI yang mengelola preset aktif, sinkronisasi dengan `DesktopSettings`, konversi ke `gpui_component::Theme`, dan callback notifikasi untuk hot-reload tampilan.
</tasks>
