<objective>
Mengimplementasikan Auth Gate, halaman Login dengan tab QR Code (auto-refresh ~30s, live event via WebSocket, tombol retry, render visual QR) berdampingan dengan tab Phone link, serta Dialog Konfirmasi Logout dan integrasi `main.rs` aplikasi desktop.
</objective>

<tasks>
1. Buat model `state/auth.rs` yang mengelola `AuthStatus` (`Checking`, `Unauthenticated`, `Authenticated`), sinkronisasi status login dari backend (`get_status()`), dan pendengar event WebSocket (`WsEvent::QrCode`, `WsEvent::AuthSuccess`).
2. Buat komponen `views/auth/login.rs` dan `views/auth/qr.rs` dengan tab switcher (QR vs Phone), kotak render QR matrix, spinner loading, error & retry, instruksi 3 langkah scan, dan tab info phone-link.
3. Buat dialog konfirmasi logout (`components/dialogs/logout.rs`) dan rakit entry point aplikasi di `main.rs` yang menginisialisasi `Root`, `ThemeManager`, `AuthState`, `WsClient`, `AppShellView`, dan transisi gate autentikasi.
</tasks>
