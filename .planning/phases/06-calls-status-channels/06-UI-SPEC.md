# Phase 6: Calls + Status + Channels - UI Design Contract

**Created:** 2026-09-09
**Status:** Approved

## 1. Visual Hierarchy & Dimensions

- **Incoming Call Modal:** Centered dialog, width `360px`, pulsing avatar, caller name, call type badge (Audio/Video), Accept (green) and Decline (red) action buttons.
- **Active Call Overlay:** Floating widget (top-right or docked), min-width `300px`, call duration timer, participant avatars/video preview, controls bar: Mic Toggle, Video Toggle, Add Member, Hang Up (red button).
- **Status Story Tray:** Horizontal scroll container at top of status page, circular avatars with gradient/primary ring for unviewed, muted border for viewed, user's own status at start with "+" badge.
- **Status Viewer Modal:** Fullscreen black background, top progress segment bars corresponding to number of stories, avatar and sender name with timestamp, center text or media, bottom caption.
- **Channels View:** Left channel directory (320px), right channel feed displaying posts with timestamp, media/text, view count, and emoji reaction counts.
