# Plan 06-01: Call State Machine & Overlay

## Goal
Mengimplementasikan state machine panggilan (audio/video, 1:1 dan grup), filtering riwayat panggilan, video upgrade flow, serta global call overlay (incoming call dialog dan active call floating widget).

## Proposed Changes
- `desktop-gpui/crates/app/src/state/call.rs`:
  - `CallManager`: tracking active call, incoming call, duration calculation, mute/speaker toggles, video upgrade requests
  - `CallHistoryState`: filtering berdasarkan direction, type, status, target
- `desktop-gpui/crates/app/src/components/call_overlay.rs`:
  - `CallOverlayComponent`: incoming call modal & active call floating bar
- Unit tests memverifikasi lifecycle panggilan dan transisi status.
