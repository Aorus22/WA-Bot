# Plan 05-03: Chat Info Sheet & Group Administration Panel

## Goal
Mengimplementasikan Chat Info Sheet (drawer info chat) yang memuat tab Media, Dokumen, Link, serta Tab Anggota & Pengaturan Grup lengkap dengan kemampuan admin (tambah, keluarkan, promote, demote anggota, ganti deskripsi, kontrol invite link, dan leave group).

## Proposed Changes
- `desktop-gpui/crates/app/src/components/chat_info_sheet.rs`:
  - State dan data model: tab selection, group participant roles, group setting toggles
  - Aksi admin: promote, demote, remove participant, invite link generation/revocation
- Integrasi ke `ChatAreaState` / `AppShellView`.
