# Plan 05-01: Rich Message Bubbles & Interactive Types

## Goal
Mengimplementasikan bubble pesan interaktif dan kaya: Poll (dengan tally live & vote toggle), Lokasi (koordinat, nama tempat, maps url), Kontak (kartu nama, vcard), View-Once tile (gated guard), Link preview card, Forwarded label, serta marker Deleted & Edited.

## Proposed Changes
- `desktop-gpui/crates/app/src/components/rich_bubbles.rs`:
  - `PollHelper`: penghitungan vote option, percentage tally, multi/single select toggle
  - `LocationHelper`: formatting lokasi dan Google Maps URL generator
  - `ContactHelper`: formatting kartu kontak dan vcard extraction
  - `ViewOnceHelper`: status check (opened vs closed/viewed)
- Unit tests memverifikasi logika penghitungan poll, link preview, dan view-once gating.
