# Plan 05-02: Media Attachments & Voice Note Player

## Goal
Mengimplementasikan penanganan lampiran media (image, video, document, audio, gif, sticker), komponen pemutar voice note (durasi + playback state), serta modal Media Viewer untuk inspeksi resolusi penuh dan aksi unduh file.

  - `MediaViewerState`: URL aktif, tipe media, modal visibility, trigger download
- Unit tests memverifikasi state transitions audio player dan media viewer.
