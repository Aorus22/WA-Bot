# Plan 04-02: Chat Sidebar & Navigation

## Goal
Mengimplementasikan komponen sidebar daftar chat lengkap dengan avatar, nama, snippet pesan terakhir, waktu, unread badge, pencarian client-side, toggle arsip, context menu pin/archive/mute, auto mark-as-read, dialog grup baru & join link, serta status history-sync.

## Proposed Changes
- `desktop-gpui/crates/app/src/components/chat_sidebar.rs`:
  - Render search input dan filter tabs (All, Unread, Groups, Archived)
  - Virtualized list chat item dengan avatar, name, lastMsg, timestamp, unread badge
  - Context menu / action popup: Pin/Unpin, Archive/Unarchive, Mute (Off/8h/1w/Forever)
  - Header actions: New Group modal, Join Group via link modal, History sync progress indicator
- `desktop-gpui/crates/app/src/components/dialogs/group.rs`:
  - `NewGroupModal` dan `JoinGroupModal`
- Integrasi ke `AppShellView` untuk rute Chat (`/chat`)
