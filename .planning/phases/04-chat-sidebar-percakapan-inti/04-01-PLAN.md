# Plan 04-01: ChatStore State Management

## Goal
Mengimplementasikan state management `ChatStore` di Rust yang memiliki paritas semantik 1:1 dengan `web/src/stores/chatStore.ts`, mencakup 6 aturan penting: ascending timestamp sorting, unread preservation, move-to-top on change, optimistic `temp-` replacement, invalidation, dan paginated entry tracking.

## Proposed Changes
- `desktop-gpui/crates/app/src/state/chat.rs`:
  - Struct `ChatStore` dan `ChatMessagesEntry`
  - Metode: `set_chats`, `upsert_chat`, `patch_chat_state`, `invalidate_messages`, `ensure_chat_state`, `set_messages`, `prepend_messages`, `append_messages`, `upsert_message`, `patch_message`, `delete_message`, `set_message_loading`
  - Unit tests memverifikasi seluruh 6 aturan semantik

## Verification
- Unit test suite di `desktop-gpui/crates/app/src/state/chat.rs` lolos via `cargo test -p wabot --lib test_chat_store`
