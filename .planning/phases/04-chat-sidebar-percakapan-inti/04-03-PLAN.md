# Plan 04-03: Active Conversation Area

## Goal
Mengimplementasikan area percakapan inti: header dengan peer presence realtime, feed pesan terpaginasi (100 pesan awal + scroll), date dividers, ticks status live, optimistic text send (`temp-`), bubble markdown, reaction chips, aksi pesan (reply, edit, delete, forward modal), serta emoji picker popover.

## Proposed Changes
- `desktop-gpui/crates/app/src/views/chat_area.rs`:
  - Chat header (peer title, avatar, presence indicator Online/Offline/Typing...)
  - Message feed with scroll pagination and date separators
  - Composer bar with auto-grow input, markdown toggle, emoji picker trigger, send button
- `desktop-gpui/crates/app/src/components/message_bubble.rs`:
  - Sent vs received styling, sender info in groups, formatted timestamp, ticks receipt
  - Markdown text rendering with code block styling
  - Reaction chips container
  - Message action menu (Reply, React, Edit, Delete, Forward)
- `desktop-gpui/crates/app/src/components/dialogs/forward.rs`:
  - Forward message modal selecting N target chats with search
- `desktop-gpui/crates/app/src/components/emoji_picker.rs`:
  - Emoji picker grid with common emojis and category tabs
